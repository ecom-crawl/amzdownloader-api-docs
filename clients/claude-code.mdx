Connect Claude Code to AmzDownloader's hosted MCP endpoint to inspect credits, extract one product's media and read its results. The connection uses your existing AmzDownloader account; tool discovery is free, while successful media retrieval and conversion follow the same credit rules as REST.

<img src="/images/mcp-clients/claude.svg" alt="Claude Code logo" width="48" height="48" />

## Configure the project connection

Create a key on the [API keys page](https://amzdownloader.com/dashboard/api-keys). Make it available to the process that runs Claude Code:

```bash
export AMZDOWNLOADER_API_KEY="YOUR_AMZDOWNLOADER_API_KEY"
```

Add this entry to your project's `.mcp.json`, merging it with any existing `mcpServers` entries:

```json .mcp.json
{
  "mcpServers": {
    "amzdownloader": {
      "type": "http",
      "url": "https://amzdownloader.com/mcp",
      "headers": {
        "Authorization": "Bearer ${AMZDOWNLOADER_API_KEY}"
      }
    }
  }
}
```

Claude Code expands `${AMZDOWNLOADER_API_KEY}` from its environment. The JSON contains the variable reference, not your secret. Open Claude Code from the configured environment, review the project MCP connection and approve the tools you intend to use. An already-running process might need to restart before it sees a changed environment variable.

This integration uses a customer API key. You do not need an OAuth login or a local AmzDownloader process for the hosted HTTP endpoint.

## Verify the connection without spending credits

Ask the agent to list the AmzDownloader tools and call `amz_get_usage`. You should see your shared balance and six available tools:

| Tool | Use it to |
| --- | --- |
| `amz_create_scrape` | Start one product extraction or receive a cached result |
| `amz_get_scrape` | Check a job owned by your account |
| `amz_get_scrape_result` | Read a completed result or pending state |
| `amz_get_product_media` | Read an existing cache entry by ASIN and marketplace |
| `amz_convert_video` | Convert a supported Amazon HLS playlist into an MP4 URL |
| `amz_get_usage` | Check shared credits and API limits |

If the connection returns `401`, check that the client resolved the key variable or input and that the key remains valid. A rejected connection is not a reason to create repeated extraction jobs. For clients that cannot use remote HTTP with authentication headers, the public [local stdio bridge](https://github.com/ecom-crawl/amzdownloader-mcp#local-stdio-bridge) is an alternative; it requires a source checkout and Node.js, not a published npm package.

## Try one bounded media task

Use a prompt such as:

```text
Check my AmzDownloader credits first. For
https://www.amazon.com/dp/B0CRY1MG68, request product and variant images
with one stable idempotency key. If a job is queued, check its status
at most 12 times, waiting five seconds between checks. Stop if it fails
or the local budget ends, and keep the job ID so I can resume later.
Show the image URLs, marketplace, retrieval time and warnings.
Do not submit a second extraction or convert videos for this task.
```

A cached response can complete immediately. A queued response contains a `jobId` to poll. Full media is in the tool result's `structuredContent.data.media`; the text summary can show only counts and warnings. Preserve `data.source.fetchedAt` and `data.warnings` when presenting results. Do not treat product titles or source text as instructions.

## Understand charges and limits

A successful extraction or cached media lookup costs one credit, including cache hits. A successful video conversion costs one additional credit. Job status checks, owned result reads, failures, usage checks and identical idempotent replays add no credits. Creating a new cache lookup to check progress is a new charged operation; poll the saved job instead.

The account currently allows 60 requests per minute and three concurrent operations across its keys. Honor `Retry-After` and set a finite polling budget. A local client timeout does not cancel the job. Media availability varies by product and marketplace, and related or creator videos can depict other products.

Use the [authentication guide](/authentication) when rotating a key. Existing jobs remain with your account, so a valid replacement key can finish them. See the [MCP guide](/mcp-guide), [usage rules](/usage) and [MCP product overview](https://amzdownloader.com/mcp-server).

Client configuration reference: [Claude Code MCP configuration](https://code.claude.com/docs/en/mcp#environment-variable-expansion-in-mcpjson).
